Repo review: rsbox-archive kyles-old-rsbox/rsbox-archive · audited 2026-07-03

Kyle Escobar's abandoned OSRS server framework (Kotlin/Java, 2022, pre-production — login reaches a welcome screen; no combat/skills/content). Source-level audit of every non-client module. Full 16-project review lives in GOAL.md §12.

✔ Worth adopting (concepts → our JS)

  • Per-tile collision bitmask — directional wall flags (N/E/S/W + corners) set on both sides of a wall, separate projectile-blocker flags, baked from object shape + rotation + footprint (width/length swap on rotation 1/3). Exactly the gap OSRS_COMPARISON §1 flags — replaces our circle colliders, unlocks line-of-sight + wall-aware pathing. → added to §15.
  • Tick loop with drift correction — measures each cycle, warns when a cycle overruns the 600 ms budget, carries the sub-millisecond remainder into the next cycle. Cheap tick-health telemetry for our fixed tick. → added to §15.
  • Strict tick pipeline order — read input → player cycles → world queue → sync tasks → flush output. Formalizes what our worldTick should guarantee before the V2 Web-Worker sim.
  • Weak / normal / strong action queues — OSRS-authentic queue priorities (strong interrupts weak; weak cleared by interfaces) for src/scheduler.js. → added to §15.
  • Hot-reloadable content scripts with suspendable wait(ticks) — validates our DevTools.reload + scheduler direction; generator-based multi-tick scripts are the JS equivalent.
  • Pluggable PlayerSerializer interface — same shape as our src/persist.js. Confirms the pattern; nothing to change.

✘ Not applicable / off-limits

  • client/ + native-client/ — a deobfuscated Jagex client (class1.java…). Jagex IP — never port, never reference.
  • toolbox/ — JVM bytecode deobfuscator + updater for reverse-engineering that client. Solves a problem we don't have.
  • cache / JS5 / varps / packet codecs — plumbing for Jagex's binary cache + protocol. We own our content format (plain JS data + validator), so this whole layer is unnecessary for us.
Verdict on "converting the Java over": we don't convert Java — rsbox is GPL-3.0 and its client is Jagex-derived, and our stack is browser JS. What transfers is architecture, and most of rsbox's architecture (event bus, content hooks, hot reload, pluggable saves, service registry, fixed tick) is already built in Crafted Realm. The three genuinely new takes — the collision bitmask recipe, queue priorities, and tick-health telemetry — are now unchecked items on the §15 checklist above.
