# Crafted Realm — NPC Pipeline (Path A, current)

The way we make creatures/NPCs: **smooth low-poly procedural geometry** (hand-authored
in code) wearing **hand-painted textures generated by Nano Banana (Gemini 2.5 Flash
Image)**. Procedural geometry keeps the OSRS silhouette and stays riggable; the AI
textures supply the painted surface detail that flat code-fills couldn't.

This replaces the deprecated Blockbench/cube approach (`ASSET_PIPELINE.md`).

---

## The three pieces

### 1. Geometry — procedural, smooth low-poly (no cubes)
Authored in `src/game2_world.js` next to `humanoid()` / `beast()`. Use organic
primitives — tapered `CylinderGeometry`, `SphereGeometry`, `ConeGeometry` — with
**gourad (smooth) shading** (plain `MeshLambertMaterial`, no `flatShading`).

Reference model: **`goblinModel(opts)`** — hunched stance, pot belly, long arms, big
ears, tusks. It must expose the standard rig hooks so animation & equipment work:

```
userData.parts = { legL, legR, armL, armR,   // pivot Groups (walkAnim/tickSwing)
                   handL, handR,              // grip Groups for held items
                   torso, head, headTop }     // body twist, head, hat/helm mount
userData.walkT = 0
```

### 2. Textures — Nano Banana (Gemini 2.5 Flash Image)
Generate **flat, hand-painted, tileable** maps and save to `assets/textures/` (served by
the dev server). Load at boot in `loadCreatureTextures()` (called from `buildTextures()`),
set `wrapS/wrapT = RepeatWrapping`, apply as a material `map`.

Generator script: `scratchpad/gemini_image.js`
```
node gemini_image.js "<prompt>" "assets/textures/<name>.png"
```
It reads `GEMINI_API_KEY` from the environment. Inject it from the Windows USER registry
so `setx` values are seen (never print/commit the key):
```powershell
$env:GEMINI_API_KEY=[Environment]::GetEnvironmentVariable("GEMINI_API_KEY","User")
```
**Prompt tips:** ask for "flat hand-painted game texture, even lighting, no shadows, no
3D, fills the frame." Avoid the words *seamless / swatch / tileable* — they tend to trip
an `IMAGE_RECITATION` refusal. Retry/reword on refusal.

### 3. Wiring
- `src/game1_data.js` — `NPC_TYPES` entry with `model:'<name>'`.
- `src/game3_systems.js` — `spawnNpc` branch: `else if(t.model==='<name>') mesh = <builder>({scale:t.size});`
- `src/game5_main.js` — walk anim is generic: `if(parts.legL) walkAnim(...)`, so any rigged biped animates automatically.
- Place it with `spawnNpc('<name>', x, z)` in a `populate*()` in `src/game4_ui.js`.

## Roadmap on this pipeline
- Apply the texture treatment to the **player/humanoid** (currently flat-coloured).
- Generate **per-creature skin maps** (different monsters) + a **face decal** option.
- Build an in-browser **NPC editor**: pick body type, tweak proportions/features/colours,
  generate & assign a texture, export the NPC definition.
- Use Gemini for **inventory item icons** (2D — a strong fit).
