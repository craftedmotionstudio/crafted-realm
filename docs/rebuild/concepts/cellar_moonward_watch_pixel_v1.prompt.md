# The Moonward Watch — image-generation prompt

Mode: built-in image generation

Use case: illustration-story

Style/medium: authentic limited-palette 8-bit pixel art, visibly blocky square pixels, simple chunky silhouettes, early fantasy computer-game illustration, warm and handmade rather than glossy

Lighting/mood: cozy amber twilight with muted navy sky and warm torchlit tower window

Constraints: original fantasy imagery; no resemblance to a specific existing game asset; no text, logos, watermark, UI, photorealism, gradients, blur, anti-aliased edges, or modern objects
